# Naver Map Verify Skill - 네이버지도 장소 검증

## Core Purpose

웹 검색으로 찾은 장소를 **네이버지도에서 직접 검증**하여:
1. 장소 실존 여부 확인
2. 현재 영업 상태 및 영업시간 확인
3. 별점/리뷰 수로 신뢰도 판단
4. TV 방송 출연 여부로 핫플레이스 감지
5. 네이버지도 직접 링크 제공

---

## Input Parameters

| 파라미터 | 필수 | 설명 | 예시 |
|----------|------|------|------|
| `place_name` | ✅ | 검증할 장소명 | "테라로사 커피공장" |
| `location` | ⬚ | 지역 (정확도 향상) | "강릉", "서울 성수동" |
| `check_hotplace` | ⬚ | 핫플레이스 판정 여부 | true/false (기본: true) |

---

## Output Structure

### 단일 장소 검증 결과

```markdown
## 검증 결과: {place_name}

| 항목 | 결과 |
|------|------|
| **존재 여부** | ✅ 확인됨 / ❌ 미확인 |
| **정식 명칭** | {네이버지도 상 정식 명칭} |
| **카테고리** | {카페/음식점/관광지 등} |
| **주소** | {전체 주소} |
| **영업 상태** | 영업중 / 영업종료 (HH:MM 오픈) |
| **별점** | ⭐ {X.XX} |
| **리뷰 수** | 방문자 {N}개 / 블로그 {N}개 |
| **편의시설** | {주차, 휠체어 등} |
| **핫플 여부** | ⚠️ 핫플레이스 / ✅ 일반 |
| **핫플 근거** | {TV출연 정보 또는 "해당없음"} |

### 네이버지도 링크
🔗 https://map.naver.com/p/entry/place/{place_id}
```

## Execution Workflow

### Step 1: 네이버지도 검색

```
Playwright 실행:
1. browser_navigate: https://map.naver.com/p/search/{location} {place_name}
2. browser_wait_for: 2초 대기 (검색 결과 로딩)
3. browser_snapshot: 검색 결과 확인
```

### Step 2: 검색 결과 판정

```
IF 검색 결과 없음:
  → 존재 여부: ❌ 미확인
  → 종료

IF 검색 결과 있음:
  → 첫 번째 결과 클릭
  → Step 3 진행
```

### Step 3: 상세 정보 추출

```
Playwright 실행:
1. browser_click: 첫 번째 검색 결과 클릭
2. browser_snapshot: 상세 페이지 캡처

추출 항목:
- 정식 명칭 (heading level=1)
- 카테고리 (장소명 옆 표시)
- 주소 (주소 버튼 텍스트)
- 영업 상태 (영업시간 버튼 텍스트)
- 별점 (별점 텍스트)
- 리뷰 수 (방문자/블로그 리뷰 버튼)
- 편의시설 (편의 섹션)
- TV 방송 정보 (TV방송정보 섹션) ← 핫플 판정용
```

### Step 4: 핫플레이스 판정

```
핫플레이스 조건 (하나라도 해당 시):
  ⚠️ TV방송정보 섹션 존재
  ⚠️ 방문자 리뷰 10,000개 이상
  ⚠️ 블로그 리뷰 5,000개 이상

판정 결과:
  - 조건 해당 → "⚠️ 핫플레이스" + 근거 표시
  - 조건 미해당 → "✅ 일반"
```

### Step 5: 링크 추출

```
URL에서 place_id 추출:
- URL 패턴: /place/{place_id}?
- 직접 링크 생성: https://map.naver.com/p/entry/place/{place_id}
```

여러 장소를 한 번에 검증할 때:

```

  - name: "테라로사 커피공장"

  - name: "순두부젤라또"
    location: "강릉"
  - name: "강릉중앙시장"
    location: "강릉"
```

### Output

| 1 | 테라로사 커피공장 강릉본점 | ✅ | 영업종료 (09:00) | 4.39 | 19,638 | ⚠️ TV | [지도](url) |
| 2 | 순두부젤라또 | ✅ | 영업중 | 4.52 | 3,241 | ✅ | [지도](url) |

## Integration with Travel Planner

### travel-planner 스킬과 연동

```
travel-planner Step 3 (검증) 에서:
  1. 웹 검색으로 후보 장소 수집
  2. naver-map-verify 호출하여 더블 검증
  3. 검증 실패 장소 제외
  4. 핫플레이스 판정 → Step 3.5 필터링에 활용
```

### 연동 예시

```markdown
## 검증 요약 (네이버지도 더블체크)

| 장소 | 웹검색 | 지도검증 | 최종판정 |
|------|--------|----------|----------|
| A카페 | ✅ 발견 | ✅ 존재, 영업중 | ✅ 추천 |
| B식당 | ✅ 발견 | ❌ 미확인 | ❌ 제외 |
| C맛집 | ✅ 발견 | ⚠️ 핫플 (TV) | ⚠️ 대안 검토 |
```

## Error Handling

| 상황 | 대응 |
|------|------|
| 검색 결과 없음 | "❌ 미확인 - 장소명/지역 재확인 필요" |
| 동일 이름 여러 개 | 지역 기반 첫 번째 결과 선택 + 주소 표시 |
| 페이지 로딩 실패 | 2초 추가 대기 후 재시도 |
| 상세 정보 일부 누락 | 확인된 정보만 표시, 누락 항목 "정보없음" |
