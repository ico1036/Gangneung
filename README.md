# 강릉 여행 가이드

**The Resonant Life** - 깨우치고, 머물며, 남기다

강릉의 3대 유산(오죽헌, 선교장, 참소리박물관)을 통해 나의 과거, 현재, 미래를 재정립하는 '성찰의 여정'을 위한 여행 가이드입니다.

- 안목 카페거리 15곳 검증 정보
- 경포 식당 10곳 (일요일 영업, 40인 단체 가능)
