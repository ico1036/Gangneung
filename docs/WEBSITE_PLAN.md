# 안목 카페거리 완벽가이드 - 웹사이트 기획서

## 1. 프로젝트 개요

### 목표
- 강릉 안목 카페거리의 모든 카페를 검증된 정보로 제공
- 여행 그룹이 쉽게 카페를 선택할 수 있도록 지원
- GitHub Pages를 통한 무료 호스팅 및 배포

### 타겟 사용자
- 강릉 여행을 계획 중인 그룹 (친구, 가족, 커플)
- 안목해변을 방문하는 관광객
- 바다뷰 카페를 찾는 사람들

## 2. 정보 구조 (IA)

```

│   ├── 전체 카페 목록

│   ├── 루프탑 카페

│   ├── 기본 정보 (주소, 전화, 영업시간)
│   ├── 메뉴 & 가격대
│   ├── 특징 태그
│   ├── 네이버지도 링크
```

| naver_rating | 네이버 평점 | |

## 4. 기술 스택

### 프론트엔드
- **HTML5 + CSS3 + Vanilla JS** (심플하고 빠른 로딩)
- 또는 **React + Tailwind CSS** (인터랙티브한 필터링)

### 호스팅
- GitHub Pages (무료, HTTPS 지원)

### 데이터
- JSON 또는 MD 파일로 카페 데이터 관리
- 정적 사이트 생성

---

## 5. 페이지별 상세 기획

### 5.1 메인 페이지
- 히어로 이미지: 안목해변 + 카페거리 전경
- 간단한 소개 텍스트
- 빠른 필터 버튼 (오션뷰 / 루프탑 / 24시)
- 인기 카페 TOP 5 카드
- 총 카페 수 & 마지막 업데이트 날짜

### 5.2 카페 목록 페이지
- 필터 사이드바
  - 뷰 타입
  - 가격대
  - 특징 (와이파이, 주차, 단체석 등)
- 카드형 카페 목록
- 정렬 옵션 (평점순, 리뷰순, 이름순)

### 5.3 카페 상세 페이지 (모달 또는 별도 페이지)
- 대표 이미지
- 기본 정보 블록
- 네이버지도 임베드 또는 링크
- 특징 태그
- "네이버지도에서 보기" 버튼

### 5.4 추천 코스 페이지
- 카드형 코스 목록
- 코스별 포함 카페 및 예상 소요시간

## 7. 개발 단계

### Phase 1: 데이터 수집
1. 네이버지도에서 안목 카페거리 카페 목록 수집
2. naver-map-verify 스킬로 각 카페 정보 검증
3. MD 또는 JSON 파일로 데이터 정리

### Phase 2: 웹사이트 개발
1. 프로젝트 구조 설정
2. 메인 페이지 개발
3. 카페 목록/상세 기능 개발
4. 필터링 기능 구현
5. 반응형 디자인 적용

### Phase 3: 배포
1. GitHub 저장소 생성
2. GitHub Pages 설정
3. 도메인 연결 (선택)

## 9. 검증 프로세스

naver-map-verify 스킬을 사용하여 다음을 검증:
1. 카페 존재 여부 (영업 중인지)
2. 영업시간 정확성
3. 네이버 평점 및 리뷰 수
4. 핫플레이스 여부
5. 정확한 네이버지도 링크

최소 10개 이상의 카페를 개별 검증
